Основные ссылки на соглашения, шаблоны и статьи, которые считаются “золотым стандартом” в индустрии:

1. Оригинальная статья (Michael Nygard)¶

Базовый стандарт. Это та самая статья, с которой всё началось. В ней описана структура из 5 частей (Title, Context, Decision, Status, Consequences).

Ссылка: https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions

2. GitHub ADR (актуальный шаблон от сообщества)¶

Самый популярный репозиторий с шаблонами и инструментами для ведения ADR. Здесь закреплены современные форматы, включая добавление “Alternatives” и “Date”.

Ссылка: GitHub - joelparkerhenderson/architecture-decision-record

Прямой шаблон: ADR Template (Markdown)

3. Национальный реестр США (US National Archives) — MADR¶

Формат MADR (Markdown Any Decision Records), используемый в государственных и крупных корпоративных проектах. Более строгий, с четкими секциями.

Ссылка: MADR - Markdown Architectural Decision Records

4. ThoughtWorks Technology Radar (рекомендация)¶

ThoughtWorks (крупное IT-консалтинговое агентство) официально рекомендует использовать ADR для документирования архитектуры.

Ссылка: ThoughtWorks - ADR

5. Инструменты (для работы с ADR)¶

Если вы хотите автоматизировать создание и ведение ADR:

adr-tools (CLI утилита для создания ADR): GitHub - npryce/adr-tools Log4brains (интерактивная документация + ADR): GetHub - thomvaill/log4brains
