Что должно входить в документацию проекта для другого разработчика?
===================================================================

Что должно быть в документации для нового разработчика:

- Общее описание сервиса и его место в системе
- Все ADR с объяснением почему выбраны те или иные технологии
- C4-диаграммы (контекст, контейнеры, компоненты)
- OpenAPI-спецификация (Swagger)
- Схема БД (ER-диаграмма для PostgreSQL, структуры для MongoDB)
- Инструкция по запуску (Docker Compose, .env)
- Как устроен CI/CD
- Как запускать тесты
- Где смотреть логи и метрики

Условия для масштабирования (пороги нагрузки, при которых нужно добавлять ресурсы)
