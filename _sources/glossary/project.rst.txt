========================================
Глоссарий терминов
========================================

.. glossary::

   ADR
      Architecture Decision Record — документ, фиксирующий архитектурное решение

   ASGI
      Asynchronous Server Gateway Interface — стандарт для асинхронных веб-серверов

   Celery
      Асинхронная очередь задач для Python

   Clean Architecture
      Архитектурный подход с разделением на слои (Domain, Application, Infrastructure)

   DI
      Dependency Injection — внедрение зависимостей

   FastAPI
      Современный веб-фреймворк для Python на основе ASGI

   RAG
      Retrieval-Augmented Generation — метод улучшения ответов ML-модели

   SSE
      Server-Sent Events — технология для real-time уведомлений

   Pydantic
      Библиотека для валидации данных в Python
