========================================
Общее описание сервиса
========================================

Что это за сервис?
===================

**Tech Task CHKPZ** — это бэкенд-сервис для взаимодействия с ML-моделью.
Сервис обеспечивает:

- Приём запросов от пользователей
- Асинхронную обработку через очередь задач
- Отдачу результатов в реальном времени (SSE)
- Хранение истории диалогов

Ключевые возможности
=====================

1. **Асинхронная обработка** — пользователь не ждёт ответа модели
2. **Real-time уведомления** — результат приходит через SSE
3. **Масштабируемость** — горизонтальное масштабирование воркеров
4. **Отказоустойчивость** — автоматические повторные попытки (retry)
