ADR convention sources
======================

.. toctree::
   :maxdepth: 2

   article 

Основные ссылки на соглашения, шаблоны и статьи, которые считаются
"золотым стандартом" в индустрии:

1. Оригинальная статья (Michael Nygard)
---------------------------------------

Базовый стандарт. Это та самая статья, с которой всё началось.
В ней описана структура из 5 частей (Title, Context, Decision, Status, Consequences).

Ссылка: `<https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions>`_

2. GitHub ADR (актуальный шаблон от сообщества)
-----------------------------------------------

Самый популярный репозиторий с шаблонами и инструментами для ведения ADR.
Здесь закреплены современные форматы, включая добавление "Alternatives" и "Date".

Ссылка: `GitHub - joelparkerhenderson/architecture-decision-record <https://github.com/architecture-decision-record/architecture-decision-record>`_

Прямой шаблон: `ADR Template (Markdown) <https://github.com/architecture-decision-record/architecture-decision-record/blob/main/templates/adr-template.md>`_

3. Национальный реестр США (US National Archives) — MADR
--------------------------------------------------------

Формат MADR (Markdown Any Decision Records), используемый в государственных и крупных корпоративных проектах.
Более строгий, с четкими секциями.

Ссылка: `MADR - Markdown Architectural Decision Records <https://adr.github.io/madr/>`_

4. ThoughtWorks Technology Radar (рекомендация)
-----------------------------------------------

ThoughtWorks (крупное IT-консалтинговое агентство) официально рекомендует использовать ADR для документирования архитектуры.

Ссылка: `ThoughtWorks - ADR <https://www.thoughtworks.com/radar/techniques/lightweight-architecture-decision-records>`_

5. Инструменты (для работы с ADR)
---------------------------------

Если вы хотите автоматизировать создание и ведение ADR:

adr-tools (CLI утилита для создания ADR): `GitHub - npryce/adr-tools <https://github.com/npryce/adr-tools>`__
Log4brains (интерактивная документация + ADR): `GetHub - thomvaill/log4brains <https://github.com/thomvaill/log4brains>`_
