Если серверы в закрытом контуре без интернета, как вы будете ставить новые библиотеки?
======================================================================================

В закрытом контуре без интернета для сборки Docker-образов 
я бы использовал локальный репозиторий зависимостей:

- Для Python-пакетов — поднял бы Nexus/Artifactory, который хранит все нужные библиотеки.
  В Dockerfile указываю внутренний индекс-URL, чтобы pip брал пакеты оттуда.
- Для базовых Docker-образов — поднял бы локальный Docker Registry, куда заранее загружены все
  необходимые образы (python, postgres, mongo). В Dockerfile ссылаюсь на этот внутренний реестр.
- Обновление зависимостей — либо через защищенный выход в интернет (если политика безопасности позволяет),
  либо путем физического переноса новых библиотек на носителе.
- Безопасность — перед загрузкой новых зависимостей обязательно проверяю их через Trivy/Clair
  на наличие уязвимостей.
