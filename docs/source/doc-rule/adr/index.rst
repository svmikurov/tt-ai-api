Порядок фиксации архитектурных решений
======================================

Все архитектурные решения документируются в репозитории проекта в формате ADR (Architecture Decision Records).
Это reST-файлы в папке ``/docs/adr/``, где каждый файл описывает:

- одно решение
- его контекст
- альтернативы
- последствия
  
Диаграммы Draw.io сохранятся рядом с ADR.
