======================================
ADR-005: Предотвращение блокировки API
======================================

Статус
======

**Черновик**

Контекст
========

От клиентов в реальном времени поступают сотни запросов к ML-модели.
Долгие ответы ML-модели блокируют обработку запросов в API.
При переполнении пула обработки новые запросы клиентов не принимаются.
Система деградирует: запросы клиентов перестают обрабатываться.

Решение
=======

Вынести блокирующие вызовы ML-модели из API в фоновый процесс.

Альтернативы:
-------------

1. **Вертикально масштабировать ML-модель**:
   Увеличить скорость вычисления ML-модели.
   Просто в разработке, не требует увеличения компонентов системы.
   Дорого, имеет физический предел.

2. **Ограничить количество обрабатываемых запросов к API**:
   Просто в реализации, контролируемая деградация системы.
   Ухудшение пользовательского опыта.

Последствия
===========

Положительные
-------------

1. Клиент сразу получит ответ от API, что запрос принят.
2. Все запросы клиентов будут обработаны без деградации системы по причине загруженности ML-модели.

Отрицательные
-------------

1. Усложнение системы компонентами обеспечения вызовов ML-модели из API в фоновом процессе.
