======================================
ADR-005: Предотвращение блокировки API
======================================

Статус
======

**Черновик**

Контекст
========

От клиентов в реальном времени поступают сотни запросов к ML-модели.
Долгие ответы ML-модели блокирует API.
Блокировка API ставит в ожидание обработку запросов клиентов,
а при переполнении пула обработки запросов, не принимает запросы клиентов.
Система деградирует. Запросы клиентов не обрабатываются.

Решение
=======

Передать вызов API ML-модели стороннему обработчику.
