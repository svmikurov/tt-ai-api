==========================================
Выбрать способ интеграции API с ML-моделью
==========================================

Статус
======

Черновик (2026-11-09)


Контекст
========

Необходимо обеспечить стабильную работу API для запросов пользователей
к синхронной ML-модели в условиях высокой нагрузки.

Альтернативы
============

Передача файла (File Transfer)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

API  создает файл, содержащий запрос к ML-модели.
ML-модель считывает файл с запросом.
API и ML-модель согласовывают наименование, расположение,
формат, время записи/считывания, процедуру удаления файла.

Общая база (Shared Database)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Приложения используют общую логическую структуру данных,
которой соответствует единая база данных.
Обращение к общей базе данных устраняет передачу информации между приложениями.

Удаленный вызов процедур (Remote Procedure Invocation)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

ML-модель предоставляет API компоненту системы доступ к части своей функциональности
посредством удаленного вызова процедур.
Взаимодействие осуществляется синхронно в условиях режима реального времени.

Обмен сообщениями
~~~~~~~~~~~~~~~~~

API размещает сообщение в общем канале, которое потом считывается ML-моделью.
Приложения должны согласовать канал, а также формат сообщения.
Взаимодействие между приложениями осуществляется в асинхронном режиме.

Позволяет перенести ответственность за передачу информации на систему передачи сообщений (Messaging).
