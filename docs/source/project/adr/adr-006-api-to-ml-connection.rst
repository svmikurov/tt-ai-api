================================================================
ADR-006: Использование Redis и Celery для связи API с ML-моделью
================================================================

Статус
======

**Черновик**

Контекст
========

См.:

- :doc:`./adr-001-use-fastapi`
- :doc:`./adr-005-avoid-api-blocking`

Вызов ML-модели делегируется воркеру посредством брокера сообщений.

Решение
=======

Используем Redis для хранения запросов клиентов, статуса обработки запроса 
и результата вызова ML-модели.
Используем Celery для вызова ML-модели.
