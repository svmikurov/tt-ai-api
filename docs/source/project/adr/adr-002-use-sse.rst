===============================================================
ADR-002: Выбор SSE для рендеринга пользователю ответа ML-модели
===============================================================

Статус
======

**Черновик**

Контекст
========

См: :doc:`./adr-001-use-fastapi`

С клиентом создается постоянное соединение для отправки ему ответа ML-модели.
После отправки, соединение с клиентом закрывается.

Решение
=======

Использовать Send-Server-Event соединение.

**Альтернативы**:

- **WebSocket** - Позволяет отправлять клиенту данные во время постоянного соединения,
  требует больше ресурсов для создания соединения.
  **Отклонен**: требует больше ресурсов для создания соединения.

**Обоснование**:

- Требует мало ресурсов для установления и поддержки постоянного соединения.
- Легко восстанавливается при разрыве соединения.

Последствия
===========

**Положительные**:

- Быстрая разработка с использованием фреймворка FastApi.

**Отрицательные**:

- При добавлении функциональности отправки данных клиентом во время соединения,
  придется заменять на WebSocket.
