===================
Структура ADR файла
===================

Заголовок
=========

eng: Title

Краткое название решения.

Статус
======

eng: Status

Черновик
--------

eng: Draft

На рассмотрении
---------------

eng: Under Review

Принято
-------

eng: Accepted

Отклонено
---------

eng: Rejected

Заменено
--------

eng: Superseded

**Пример**: Заменено (ADR-012)

Устарел
-------

eng: Deprecated

Контекст
========

eng: Context

Описание проблемы и ситуации.

Решение
=======

eng: Decision

Что решили сделать.

Последствия
===========

eng: Consequences

Плюсы, минусы, компромиссы.

Альтернативы
============

eng: Alternatives

[Alternative 1]
---------------

[**Описание** (eng: Description): что предлагается сделать.]

[**Преимущества** (eng: Advantages): почему это может быть хорошим решением.]

[**Недостатки или причина отклонения** (eng: Drawbacks or reason for rejection): почему этот вариант не выбран.]
