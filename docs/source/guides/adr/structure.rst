Структура ADR файла

Заголовок
=========

eng: Title

======

eng: Status

--------

eng: Draft

На рассмотрении
---------------

eng: Under Review

Принято
-------

eng: Accepted

---------

--------

eng: Superseded

-------

Описание проблемы и ситуации.
